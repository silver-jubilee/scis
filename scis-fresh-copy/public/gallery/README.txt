SC&IS Silver Jubilee — photo gallery
====================================
Drop photographs into this folder (jpg, jpeg, png, webp, avif) and reload the page.

 • Files placed directly here appear under "All".
 • Each sub-folder becomes an album chip, e.g.  gallery/Alumni 2019/IMG_01.jpg
 • Optional captions: create captions.json next to this file, e.g.
       { "IMG_01.jpg": "Alumni meet, 2019", "Alumni 2019/IMG_02.jpg": "Poster session" }
   Without it, the caption is made from the file name.
 • Tip: export photos at ~2000 px on the long edge (≤ 400 KB each) for a fast page.
